# Verkstaden5 - Vectric Database

Välkommen till den officiella verktygsdatabasen från [Verkstaden5](https://verkstaden5.com). Denna databas (`.vtdb`) är skapad för användare av Vectrics programvaror (VCarve Desktop, VCarve Pro, Cut2D och Aspire).

## 📥 Nedladdning & Installation
För att alltid ha den senaste versionen med optimerade skärparametrar (matning, varvtal, skärdjup), ladda ner filen från vår officiella sida:
👉 **[Ladda ner verktygsdatabasen för Vectric här](https://verkstaden5.com/pages/frasstalsdatabas)**

### Vad innehåller databasen?
- **Verktyg:** Pinnfräsar, planfräsar, V-bits och kompressionsfräsar från vårt sortiment.
- **Material:** Färdiga parametrar för mjukt/hårt trä, MDF, kryssfaner (plywood), aluminium och plast.
- **Organisation:** Verktygen är snyggt sorterade så att du enkelt kan importera dem utan att skriva över dina befintliga verktyg.
